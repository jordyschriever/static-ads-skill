# Interview: ask what goes in

The user decides what the ads say and which ingredients they use. Ask after a quick discovery pass, so every option is concrete. Use AskUserQuestion:
- at most 4 questions per call, 2 to 4 options each ("Other" is added for them)
- `multiSelect` where several answers fit
- your recommendation first, marked "(Recommended)"

Write every answer into `ads/BRAND.md` or the campaign brief.

## Round 1: the brief

| Question | Options (adapt to what you found) |
|---|---|
| Where will the ads run? (multi) | Meta feed and stories / LinkedIn / X / Google Display banners |
| What is the goal? | Sign-ups or trials / Awareness of a launch / Retargeting visitors / Event or webinar |
| Who is it for? | The 2 or 3 audiences the landing page or docs name, in their words |
| Which features or messages? (multi) | The 3 or 4 strongest features you found, by their product names |

Then derive the formats from the channels (see formats.md) and confirm the list in one line rather than asking.

## Round 2: the ingredients

| Question | Options (offer only what the product can support) |
|---|---|
| What carries the visual? | Real product UI, cropped close / A single component as hero (a card, a chart, a result) / Type only, big headline on brand color / Brand pattern or illustration (only if they have one) |
| What proof goes on it? (multi) | A metric / A customer quote / Customer or partner logos / None |
| Which call to action? | The CTA wording the site already uses (list them) / "Start free" / "Book a demo" / Let the platform button do it (no CTA in the image) |
| How many variants per concept? | 2 headlines, same visual (Recommended) / 2 visuals, same headline / 3 concepts, 1 variant each / Only one ad |

## Round 3 (only if needed)

- Dark or light, if the product has both.
- Price or offer on the image, with its exact qualifier.
- Claims that need approval before anything is shown.
- Text language(s) and whether each language gets its own set.

## Don't ask

- What the code answers: colors, fonts, radius, spacing, the logo.
- Taste you can show: make 3 rough style frames and let them react.
